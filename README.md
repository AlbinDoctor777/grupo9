# Sistema de Gestión de Canciones

## Descripción

Este proyecto consiste en el desarrollo de un sistema de gestión de canciones utilizando el lenguaje de programación C++.

El sistema permite registrar, buscar, actualizar, eliminar, ordenar y mostrar información de canciones mediante una estructura de datos tipo lista implementada con arreglos y estructuras.

## Objetivo

Desarrollar una aplicación que permita administrar una colección de canciones aplicando conceptos fundamentales de estructuras de datos y programación estructurada.

## Funcionalidades

* Registro de canciones.
* Búsqueda de canciones por código.
* Actualización de información.
* Eliminación de canciones.
* Ordenamiento alfabético por título.
* Visualización de canciones registradas.

## Estructura de Datos Utilizada

Se utilizó una lista implementada mediante un arreglo de estructuras (`struct`) para almacenar la información de las canciones.

Cada canción contiene los siguientes datos:

* Código
* Título
* Artista
* Género
* Duración

## Algoritmos Utilizados

### Búsqueda Secuencial

Permite localizar una canción recorriendo la lista y comparando los códigos registrados.

### Ordenamiento Burbuja (Bubble Sort)

Permite ordenar alfabéticamente las canciones según su título.
